Дата: 2026-11-03. Дополнение к [навигации, галерее и справке](navigation-gallery-and-help.md). [Семь базовых экранов и их назначение](../../future/gui.md).

**В текущем Rust GUI-макете уже используются `bg.jpg`, `NM_Logo.png` и SVG оболочки.** Аватары, провайдерские значки, иллюстрации руководства и остальные ресурсы подготовлены для следующих экранов. Наличие файла не означает реализацию соответствующей функции.

## Источник и проверяемость

Источник: локальный checkout `D:/NeuroMitaTest/NeuroMitaOrigin/09082025/NeuroMita`, HEAD [7f6b2625d355b1e4e22ed078283df9cfac2468ca](https://github.com/Atm4x/NeuroMita/tree/7f6b2625d355b1e4e22ed078283df9cfac2468ca). Взяты `assets/` целиком и статические ресурсы `src/ui/icons/`. Все перенесённые исходные файлы отслеживаются Git в этой ревизии. У восьми текстовых файлов байты checkout отличаются от Git blob только CRLF/LF; сохранены именно байты локальных файлов, без нормализации.

В [assets/manifest.json](../../assets/manifest.json) для каждого файла указаны исходный путь, путь назначения, размер и SHA-256. Для ресурсов Python также записаны Git blob ID и соответствие ревизии с учётом переводов строк. Отдельный раздел содержит семь пользовательских скриншотов и их исходные имена. Абсолютные пути временного каталога не требуются для использования пакета.

Перенесено 48 графических файлов, два исходных документа о провайдерских значках и исходный пустой `.gitkeep`: 11 594 993 байта. Семь скриншотов занимают ещё 2 615 372 байта. Полный оригинальный набор сохранён, включая файлы без найденного активного потребителя; они явно выделены ниже.

## Сохранённый резерв

`assets/launcher_ui/bg_old.jpg`, `logo.png`, `icon.png`, `icon.ico` скопированы как часть исходного набора. В исследованных `.py`-файлах не найдено прямого использования этих четырёх путей действующим интерфейсом. Для нового GUI базовыми являются `bg.jpg` и `NM_Logo.*`; резервные изображения не следует автоматически подключать вместо них. Отсутствие найденного потребителя не доказывает, что файл никогда не использовался внешними инструментами.

## Что не является готовым файлом из assets

Дополнение после реализации оболочки: для используемых через QtAwesome пиктограмм перенесены 17 исходных SVG из Font Awesome 6.7.2 и Material Design Icons 7.4.47. Они находятся в `assets/icons/fontawesome/` и `assets/icons/material/`; [shell-sources.json](../../assets/icons/shell-sources.json) содержит URL и SHA-256, рядом сохранены лицензии. Они подключены к Slint как векторные изображения, без Python-пакета и без вырезания из скриншотов.

Большинство кнопочных и навигационных иконок генерируется из шрифтов QtAwesome: `src/ui/widgets/launcher_shell_sidebar.py:256,302`, `src/ui/widgets/chat_panel.py:361–521`, `src/ui/widgets/gallery_grid.py:90`. Например: `fa5s.heart`, `fa5s.database`, `fa5s.paperclip`, `fa5s.camera`, `fa5s.paper-plane`. Их PNG/SVG нет в исходном наборе; они не извлекались из скриншотов и не копировались из установленного Python-пакета. При разработке Slint GUI понадобится выбрать источник этих глифов или векторных иконок. Подключать QtAwesome/PyQt ради них не требуется.

Шрифт оболочки задан как `Segoe UI`, затем `Arial`, затем системный sans-serif (`src/styles/shell/launcher_shell.py:52`). Файлов этих системных шрифтов в наборе нет, они не скопированы.

Фото галереи, история, настройки, ключи, пользовательские изображения и AI-модели не входят в статические ресурсы приложения и сюда не переносились. Изображения галереи внутри пользовательского референса сохранены только как часть самого скриншота.

## Происхождение и лицензии

Вместе с SVG без изменений сохранены [SOURCES.md](../../assets/icons/providers/SOURCES.md) и [LICENSE-LobeHub](../../assets/icons/providers/LICENSE-LobeHub). Они фиксируют источники значков и MIT-лицензию набора LobeHub. Для остальных иллюстраций и брендинга сохранено происхождение из исходного проекта; новая лицензия на них этим дополнением не назначается.

Каталоги `assets/` и `future/gui-reference/` исключены из Git-нормализации текста, чтобы SVG, сведения об источниках и контрольные суммы переживали checkout без изменения байтов. Это не меняет существующие правила для `vendor/`.
