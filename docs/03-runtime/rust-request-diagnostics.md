# Диагностика запроса в Rust Core

Диагностика сохраняет разные этапы одного `RequestId`: входной текст и summary субъективного контекста, подготовленный prompt, фактическое тело запроса провайдеру, ответ до application validation, ошибку и переходы выполнения. Ошибка JSON не удаляет полученный provider body. Оборванный ответ обозначается `complete=false`; отсутствие ответа, prompt или usage показывается явно.

## Просмотр и экспорт

В интерактивном терминале работающего Core доступны:

```text
/diagnostics list 10
/diagnostics latest usage
/diagnostics REQUEST_UUID all
/diagnostics view REQUEST_UUID response
/diagnostics errors 10
/diagnostics export REQUEST_UUID response C:\Export Folder\response.json
```

Разделы: `all`, `ingress`, `prompt`, `request`, `response`, `usage`, `error`, `lifecycle`. Команды просмотра печатают JSON, который можно скопировать. Экспорт создаёт новый файл; существующий файл не перезаписывается. Родительский каталог должен существовать.

Поиск по UUID точный: если трасса отсутствует или истекла, возвращается явная ошибка, а другая трасса не подставляется. `latest` — отдельный явный выбор последнего доступного запроса; результат помечен как такой выбор. Повторный просмотр активного запроса получает свежий snapshot, ранее полученный snapshot неизменяем.

Для локальных клиентов TCP добавлены `diagnostics`, `diagnostics_recent`, `diagnostics_errors`, перечисляемые через `methods`. Например:

```json
{"command_id":"11111111-1111-4111-8111-111111111111","command":"diagnostics","character":"mita","request_id":"22222222-2222-4222-8222-222222222222","section":"usage"}
```

TCP-клиент видит только запросы своего соединения и выбранного персонажа. Терминал использует scope `Presenter`. Встроенные presenters могут обращаться к `ChatApi::diagnostics_for(DiagnosticScope::owner(...))`. Доступ по персонажу без source предназначен для доверенного владельца Core; это не разрешение удалённому клиенту читать чужие запросы.

## Токены, приватность и хранение

`usage.actual` содержит только счётчики, действительно присланные провайдером. Если их нет, поле остаётся пустым. `usage.estimated` отдельно помечает локальную оценку по числу символов; её нельзя считать биллингом или точным токенизатором модели.

Диагностические тексты скрывают настроенные ключи, их JSON/URL-представления, credential-параметры, URL userinfo/query/fragment и заголовки авторизации. Это относится к копированию, JSON-экспорту и Debug-представлению трассы. Вместо полного CharacterContext сохраняется summary; переходы не должны удерживать исходный ответ, эффекты и аудио.

По умолчанию сохраняются 64 завершённые трассы, 32 ошибки и 128 меток истёкших трасс. Один текст ограничен 16 KiB, provider body — 32 KiB, prompt — 64 сообщениями, история переходов — 32 состояниями. Поля `bytes`/`truncated` обозначают сокращение. После выхода Core диагностическая история не восстанавливается с диска.

Эта функция не является dataset. Opt-in сбор полного provider request/response, рейтинги и экспорт обучающих пар описаны отдельно в [rust-finetune-dataset.md](rust-finetune-dataset.md). Эти файлы сохраняются по явно выбранной конфигурации; диагностическая redaction не изменяет отправленный провайдеру запрос и обучающие данные.

## Проверка и границы

Проверки используют локальные fixtures: success/failure/cancel, malformed и partial body, late lookup, retention, redaction, source ownership и экспорт. Production API, платные запросы и загрузка моделей для них не нужны. Команды доступны через терминал и TCP; отдельная GUI-панель в этот срез не входит.

Референс сверки: Python `Atm4x_NeuroMita` commit `36f942106ab04522492477087e7db5ca41f0d626`, `src/core/performance_trace.py`, `src/managers/llm_request_runner.py` и аудит `docs/03-runtime/per-request-performance-traces-and-diagnostic-metrics.md`. Сохранены корреляция запроса, стадии, частичная ошибка и snapshots активных/завершённых запросов. Rust использует lifecycle своего RequestHandle и собственные границы хранения; Python fallback chain, ASR-трассы и агрегаты производительности не воспроизводятся этой функцией диагностики генерации.
