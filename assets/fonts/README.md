# Font Awesome used by Sandbox

`fontawesome6-solid-6.7.2.ttf` is copied byte-for-byte from the original Python application's QtAwesome 6.7.2 font, `venv/Lib/site-packages/qtawesome/fonts/fontawesome6-solid-webfont-6.7.2.ttf`.

SHA-256: `220d6d592b543eb991b8c11137ef0082c27d6ff6fdaa25e4335945f57a487c6c`.

Family: `Font Awesome 6 Free Solid`. Glyph codepoints in `ui/sandbox/theme.slint` come from QtAwesome's matching charmap. This uses the same icon outlines as the Qt widgets. License: [Font Awesome Free](../icons/fontawesome/LICENSE.txt), including the font's SIL OFL terms.

Text uses the system `Segoe UI Variable` family selected by the Python base QSS. Windows fonts are not redistributed.
