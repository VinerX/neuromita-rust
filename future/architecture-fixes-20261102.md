# Исправления архитектурного аудита, 2026-11-02

База: e5975e2. Статические API и существующие ContextAnchor/MitaView сохраняются. Новый обязательный объект копии Timeline не вводится.

- [x] Общая проверка структуры и последовательной применимости фактов состояния/памяти; одинаковые гарантии in-memory/SQLite.
- [x] Проверенный предметный пакет принятия с закрытыми полями; CharacterHandler не разбирает StructuredResponse.
- [x] Правила характеристик и модель памяти отделены от Timeline; контекст собирается из одного префикса истории существующими представлениями.
- [x] Отмена при TTS до принятия сообщения и эффектов; явный частичный успех при ошибке TTS.
- [x] SQLite собирается из vendor без внешней sqlite3.lib; обычный persistent bootstrap восстанавливает Timeline.
- [x] Регрессионные тесты, оба режима хранения, Clippy и форматирование.
- [x] Открытые PR оценены отдельно без автоматического merge или публикации комментариев: [результаты #55–58](pr-review-20261102.md).

Регрессии: прямой append специальных событий, неизвестный MemoryId, privacy/capacity, rollback, fork, дубликаты, merge, одно чтение префикса, TTS cancel через presenter/TCP, отсутствие предложенных памяти/working state/характеристик после отмены и восстановление ответа/памяти через production bootstrap. Анимация и streaming не объявляются реализованными.

Проверено на Windows: 178 тестов с bundled SQLite и 127 без default features; в каждом режиме один live Gemini ignored. Clippy всех targets в обоих режимах и rustfmt прошли. Проверены checksums всех 184 vendored пакетов. Linux-сборка здесь не выполнялась.
