# Speech AI runtime startup: existing installations only (2026-11-04)

Desktop `ApplicationConfig` opts into `InstalledSpeechEnvironment` and resolves selected TTS/ASR **after** `SettingsLifecycle::prepare`, so settings migrations precede worker composition. The selected model IDs and per-model options remain owned by `SettingsOwner`.

The installed environment does not invoke `AiProductionInstaller`, `uv pip install`, model downloads, or assets generation. It finds a single existing managed `uv` and pinned CPython version, reads installed overlay and backend receipts, requires an unambiguous installed backend consistent with the plugin install plan, and checks the complete `RuntimeComposition` layers. `inspect_speech_selection` verifies the effective settings and model assets before a split worker is activated. No generic Python fallback or automatic CPU/backend substitution is permitted.

ASR initializes when a recognizer is configured. Local TTS initializes only when enabled and `local_auto_load` is true; other TTS modes are not Python-worker services. If no local speech model is selected, the AI runtime is not started. Initialization failure does not block access to GUI settings; the selected service appears `Failed` through the existing runtime Presenter and the failure is also surfaced as a settings error. Partial application activation is rolled back by `AiApplicationConfig::activate`.

**Open boundaries:** runtime selections are read once on application startup; edits to an active TTS/ASR selection require explicit restart/recomposition, not silent in-place mutation. The managed Python, SDK and plugin files must already be installed and available in the configured data directories. The SDK is not yet embedded/extracted from a single packaged executable. If multiple installed revisions/backends are compatible, startup refuses to guess; a subsequent settings/installation contract must permit an explicit pinned backend/overlay revision. Runtime restart, lazy TTS activation, and live-device inference remain separate work. This change is not validated with actual speech models or microphones.
