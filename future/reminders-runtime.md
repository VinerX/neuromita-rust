# Напоминания и таймеры (#31)

Референс Python: `Atm4x/NeuroMita` / локальная `Atm4x_NeuroMita`,
`36f942106ab04522492477087e7db5ca41f0d626`. Проверены активные
`ReminderController`, `ReminderManager`, builtin `reminder` tool и их вызовы.
Rust сохраняет создание, список, изменение, удаление и автономную реакцию на
таймер; внутренний Python service locator не переносится.

## Пользовательский путь

В интерактивном терминале обычного `neuromita`:

```text
/reminder zone Europe/Moscow
/reminder now
/reminder add завтра в 18:00 | Позвонить другу
/reminder timer 10 | Напомни проверить духовку
/reminders
/reminder update 1 text Позвонить вечером
/reminder update 1 repeat daily
/reminder update 1 due 2026-12-01T18:00:00+03:00
/reminder delete 1
/reminder disable
/reminder enable
```

Записи принадлежат выбранному персонажу и ветке Timeline. `RemindersApi`
предоставляет те же типизированные операции, snapshots/observe и явный retry
по delivery UUID. Модель получает только свои активные напоминания и инструмент
`reminder` (`list/add/update/delete/timer`). Результат инструмента сохраняется
в контексте последующих обращений. Structured `reminder_add`, `timer_add`,
`reminder_delete` входят в атомарный пакет ответа: ошибочная операция отменяет
пакет, включая остальные изменения состояния. Ошибка собственно tool-вызова
возвращает видимую диагностику без изменения записей.

## Время и сохранение

Явный начальный профиль и миграция настроек v1/v2 → v3 используют UTC.
`/reminder zone local` явно определяет системную зону; ошибка определения
возвращается пользователю. Можно задать IANA-зону вручную. Изменение зоны
влияет на новые вводимые даты; ранее сохранённые записи сохраняют свою зону.
RFC3339 с offset означает абсолютное время; ISO без offset и дружелюбные
RU/EN выражения интерпретируются в выбранной зоне. Прошедшая дата отвергается.

Политика неоднозначного времени задаётся явно типом `LocalTimePolicy`.
Начальный LENIENT выбирает ранний вариант осеннего повторения часов и начало
существующего времени после весеннего разрыва; STRICT отвергает весенний разрыв.
IANA-правила включают получасовые и суточные переходы, а не только европейский DST.
`daily`/`weekly` привязаны к местному календарю, `every N seconds/minutes/hours`
к длительности. Пропущенные повторы объединяются в одно срабатывание с ближайшей
следующей датой в будущем; после простоя нет лавины пропущенных реакций.

Расписание, срабатывания и состояния доставки — факты Timeline. С обычной
SQLite-конфигурацией они переживают перезапуск. `--no-default-features`
поддерживает только явно выбранный transient Timeline, без обещания сохранения.

## Доставка и ошибки

Сначала атомарно фиксируется `ReminderFired`, затем ставится обычная реакция
в очередь персонажа. Повтор при QueueFull ограничен backoff и бюджетом попыток,
сохраняет исходное событие срабатывания. Ошибка генерации блокирует доставку
до явного `/reminder retry <delivery-uuid>` через API; автоматических повторных
платных генераций после такой ошибки нет. Accepted `ReactTo` является
доказательством доставки даже после перезапуска и даже при ошибке озвучки.
Пользовательская отмена завершает доставку без повторного запуска; выключение
Core оставляет незавершённое срабатывание для восстановления.

Глобальное отключение приостанавливает новые срабатывания и постановку в очередь,
сохраняет записи; уже начатая генерация без новых reminder-эффектов завершается обычным образом. Если модель одновременно предлагает изменить напоминания при выключенном планировщике, весь пакет отклоняется с явной ошибкой; доставка блокируется до ручного retry. Изменение
расписания/удаление делает старый результат неприменимым. Принятие ответа повторно
проверяет состояние доставки под тем же Timeline lock, что и запись ответа.

## Проверки и границы

Тесты используют ManualClock, локальный HTTP Gemini fixture и SQLite с несколькими
последовательными запусками Core. Проверяются DST/зоны/невалидные даты, смешанный
атомарный пакет, retry, cancellation, QueueFull, disabled, privacy и поздний ответ.
Живой платный API и GUI в этой приёмке не запускались. Отдельного GUI редактора,
системных уведомлений и импорта Python reminder JSON нет. Это не обещание
exactly-once внешних effects при аварийном завершении стороннего сервиса (#54).
